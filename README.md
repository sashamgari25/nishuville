# Nishuville

A personal portfolio and interactive digital archive exploring the intersection of software engineering, music, and creative expression.

## About the Project

Nishuville is a personal website designed and developed to showcase my technical projects, interests, and creative work.

The website combines retro-futurist aesthetics, editorial layouts, and analogue-inspired visual elements with modern frontend development practices.

A central feature is the **Listening Room**, an interactive collection of albums featuring personal ratings, reviews, search, filtering, and vinyl-inspired interactions.

## Planned Features

- Responsive and accessible portfolio
- Software engineering project showcase
- Interactive Listening Room
- Album search, sorting, and genre filtering
- Album and track reviews
- Creative About page
- Contact and professional links

## Technology

The project will initially use HTML, CSS, and JavaScript before introducing React.

Additional tooling, testing libraries, and deployment choices will be documented as they are adopted.
