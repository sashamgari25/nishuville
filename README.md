# Nishuville

**A personal archive of software, music and everything in between.**

Nishuville is a personal website and portfolio built to showcase my software engineering projects, music interests and creative work.

The project combines a retro-futuristic visual identity with interactive frontend features. I'm developing it incrementally, beginning with HTML, CSS and vanilla JavaScript before introducing APIs, React and a more comprehensive content-management system.

## Features

### Currently implemented

- Responsive homepage featuring software projects and favourite albums
- Dynamically generated project and album cards
- Top-five album ranking based on personal ratings
- Custom album rating system combining individual song ratings (60%) with a holistic album score (40%)
- Synthesised interface sounds using the Web Audio API
- Sound preferences saved using browser local storage
- Keyboard-accessible interactive elements

### Planned

- Music API integration for album metadata, tracklists and artwork
- React-based component architecture
- Searchable and sortable Listening Room
- Individual album pages with reviews and track ratings
- Expanded project portfolio, blog, About and Contact pages
- Private content-management interface
- Automated testing and production deployment

## Tech Stack

**Current:** HTML5, CSS3, JavaScript (ES6+), Web Audio API, localStorage

**Planned:** React, Vite, music APIs and a Git-backed or headless CMS.

## Running Locally

1. Clone the repository:

   `git clone https://github.com/sashamgari25/nishuville.git`

2. Open the project folder in your editor.

3. Serve the project using a local development server, such as VS Code Live Server.

4. Open the local website in your browser.
